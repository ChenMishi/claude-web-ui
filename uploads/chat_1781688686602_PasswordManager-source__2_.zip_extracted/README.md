# 密码管理器 (Password Manager)

一个安全、本地化、简单易用的密码管理器。所有数据加密存储于本地，无需联网。

## 功能特性

- 🔐 **加密存储** — 使用 AES (Fernet) 加密，主密码派生密钥，数据仅存在于内存明文
- 📁 **目录树管理** — 支持多级目录层级，入口归类整理，拖拽移动
- 🔍 **快捷搜索** — 实时搜索过滤，支持按目录筛选
- ⌨️ **全局热键** — 默认 `Ctrl+Alt` 一键调出快捷访问窗口，支持自定义
- 📋 **自动填充** — 双击入口用浏览器打开网址并自动键入账号密码（键盘模拟，支持禁止粘贴的网站）
- 💾 **备份还原** — 一键导出/导入加密密码库文件
- 🔒 **安全锁定** — 连续 5 次密码错误自动锁定，锁定时间逐次递增
- 🪟 **系统托盘** — 可隐藏到托盘后台运行，热键随时呼出
- 🎨 **自定义热键** — 录制任意组合键作为全局快捷键

## 系统要求

- Python 3.8+
- 操作系统：Windows / Linux / macOS

## 快速开始

### 1. 安装依赖

```bash
pip install cryptography pynput pystray Pillow
```

### 2. 运行

```bash
python main.py
```

首次运行会提示创建密码库，设置主密码后即可使用。

### 3. Windows 打包为 EXE

```bash
build.bat
```

生成的 `PasswordManager.exe` 位于 `dist/` 目录。

### 快捷访问

按下全局热键 `Ctrl+Alt` 弹出搜索窗口：

- 输入关键词实时过滤入口
- 回车 = 自动填充（先打开网址再键入账号密码）
- 双击入口 = 自动填充
- 支持目录树浏览
- Esc 关闭窗口

### 自动填充流程

1. 双击入口（或在快捷访问中选中后回车）
2. 默认浏览器打开入口网址
3. 等待页面加载后自动键入用户名 → Tab → 密码
4. 每 5 秒重试一次，最长 12 秒（约 3 次尝试）

## 数据存储

- **Windows**: `%APPDATA%/PasswordManager/vault.enc`
- **Linux/macOS**: `~/.password-manager/vault.enc`

配置文件和锁定状态存储在同一目录下。

## 安全性分析

### 加密体系

| 环节 | 算法 | 说明 |
|------|------|------|
| 密钥派生 | PBKDF2-HMAC-SHA256 | 60 万次迭代（OWASP 2023 推荐标准），16 字节随机盐 |
| 数据加密 | Fernet (AES-128-CBC) | 对称认证加密，包含 HMAC-SHA256 完整性校验 |
| 密码生成 | `secrets` 模块 | 密码学安全的随机数生成器，Fisher-Yates 洗牌 |
| 文件写入 | 原子写入 | 先写 `.tmp` 再 `os.replace`，防止写入中断损坏数据 |

### 威胁模型

**可防御的威胁：**

- 🛡️ **文件泄露** — 密码库文件被拷贝后，无主密码无法解密。PBKDF2 60 万次迭代显著增加暴力破解成本（单次尝试约 0.5–1 秒）
- 🛡️ **暴力破解** — 5 次错误后自动锁定，锁定时间逐次递增（5→10→15...分钟），有效阻断在线暴力尝试
- 🛡️ **剪贴板窃取** — 复制密码 30 秒后自动清除剪贴板
- 🛡️ **数据篡改** — Fernet 内置 HMAC 签名，任何密文篡改都会导致解密失败
- 🛡️ **写入损坏** — 原子写入机制，即使写入过程崩溃也不会丢失原有数据
- 🛡️ **传输拦截** — 完全本地运行，无网络通信，不存在中间人攻击面

**无法防御的威胁：**

- ⚠️ **内存提取** — 解锁状态下，所有密码以明文 Python 字符串存于内存中。有物理/root 访问权限的攻击者可通过内存 dump 提取数据。这是所有本地密码管理器的固有局限，Python 无法调用 `mlock`/`SecureString`。
- ⚠️ **键盘记录** — 主密码输入和自动填充均通过系统键盘，主机上的键盘记录器可捕获。自动填充使用键盘模拟（`pynput`），与手动输入等效，无法防御内核级键盘钩子。
- ⚠️ **剪贴板监视** — 手动复制密码时，密码会在剪贴板中停留最多 30 秒，此期间可被剪贴板监控程序读取。
- ⚠️ **主密码强度** — 安全性最终取决于主密码强度。弱主密码（如纯数字 8 位）可被离线字典攻击快速破解（尽管有 PBKDF2 保护）。

### 安全边界总结

```
┌─────────────────────────────────────────────┐
│  可信环境（解锁后）                          │
│  ┌─────────┐  ┌──────────┐  ┌────────────┐  │
│  │ 内存明文 │  │ 剪贴板   │  │ 键盘模拟   │  │
│  │ (风险)   │  │ (30s清除) │  │ (同手动输入) │  │
│  └─────────┘  └──────────┘  └────────────┘  │
├─────────────────────────────────────────────┤
│  不可信环境（锁定后 / 磁盘上）               │
│  ┌──────────────────────────────────────┐   │
│  │  vault.enc = PBKDF2 + Fernet 加密    │   │
│  │  ✅ 无主密码无法解密                  │   │
│  │  ✅ 篡改可检测（HMAC）                │   │
│  └──────────────────────────────────────┘   │
└─────────────────────────────────────────────┘
```

### 最佳实践建议

1. **使用强主密码** — 至少 16 位，包含大小写字母、数字、符号，避免常见词汇
2. **定期备份** — 使用内置备份功能，将备份文件存储在独立物理介质上
3. **锁定后再离开** — 离开电脑时手动锁定（点击"隐藏到托盘"或关闭窗口重新锁定）
4. **系统安全** — 保持操作系统更新，安装可信的杀毒软件，防止键盘记录器
5. **勿在共享环境使用** — 避免在网吧、公共电脑等不可信环境解锁密码库
6. **备份主密码** — 主密码丢失后数据永久无法恢复，建议将主密码安全地离线备份
